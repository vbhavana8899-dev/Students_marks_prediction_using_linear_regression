# Student Marks Prediction using Linear Regression

## About the Project
This is my first Machine Learning project. The goal is to predict students' exam scores using study habits and other student-related factors.

## Algorithm Used
- Linear Regression

## Features Used
- Study hours
- Class attendance
- Sleep hours
- Sleep quality
- Study method
- Exam difficulty
- Facility rating

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Project Workflow
1. Loaded and explored the dataset.
2. Selected input features and the target variable.
3. Converted categorical features into numerical values.
4. Split the data into training and testing sets.
5. Trained a Linear Regression model.
6. Evaluated the model using MAE and R² score.

## Results
- Mean Absolute Error (MAE): 7.86
- R² Score: 0.7331
